# מאגר נתונים — סוכן AI לבדיקת בגרות בהיסטוריה (RAG)

תחום הסוכן: **למידה מקוונת / EdTech**. מורה מעלה תשובת תלמיד מוקלדת יחד עם המחוון הרשמי,
והסוכן מציע ציון, מנמק אותו, נותן משוב ומפיק תובנות ברמת הכיתה. כדי לעשות זאת באופן מהימן
הסוכן נשען על **שני מקורות נתונים מסוג RAG** המכסים את מלוא הסילבוס של שני השאלונים:

- **022281** — בית שני, ערים וקהילות בימי הביניים, לאומיות.
- **022261** — מלחמת העולם השנייה והשואה, לאומיות וציונות, המאבק על הקמת מדינת ישראל, סוגיות נבחרות בתולדות מדינת ישראל.

ההפרדה הרעיונית בין המקורות: **מקור 1 = ולידציה / מפתח תשובות; מקור 2 = בסיס ידע לאימות עובדתי בזמן אמת.**

- **ויקיפדיה העברית** (מנוע ההרחבה המרכזי של `מאגר_ידע`) — רישיון CC BY-SA: התוכן **סוכם ונוסח מחדש** במילים מקוריות, עם ייחוס באמצעות `source_url` בכל שורה. אין העתקה מילולית של פסקאות.

- **לא נעשה** שימוש בספרי לימוד מסחריים או בפתרונות בתשלום.

- הנתונים נאספו בסקרייפינג אמיתי: ויקיפדיה דרך **MediaWiki API**, ואשנ"בים דרך הורדת PDF ישירה.
