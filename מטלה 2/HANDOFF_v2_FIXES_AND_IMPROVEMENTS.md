## 2. תיקונים שבוצעו (v2)

### ✅ 2.1 חילוץ PDF — תוקן

- `build.py` מוסיף עמודת `source_url_encoded` ל-`מאגר_ידע` עם `urllib.parse.quote(..., safe="/:?=&")`.

### ✅ 2.4 טקסונומיית פרקים — נורמלה

### ✅ 2.5 כיסוי מלא של 50 שאלות

## 5. איך להריץ מחדש את ה-pipeline

```bash
cd "AI Agents/מטלה 2"
python _build/scrape_wiki.py      # ממזג ל-_build/raw_wiki.json (מושך רק חסרים)
python _build/scrape_ashnav.py    # מוריד PDFים -> _build/raw_ashnav.json (plain get_text, ללא bidi)
# ערוך/הוסף יחידות: _build/new_units.py  (NEW_UNITS), _build/new_ashnav.py (NEW_ASHNAV)
python _build/build.py            # בונה את 3 הקבצים -> data/history_agent/
python _build/grounding.py        # מוודא ביסוס -> _build/_grounding.txt
python _build/check_urls.py       # בודק HTTP -> _build/_bad_urls.txt
```

**חשוב לגבי PDF:** `page.get_text("text")` בלבד — **אין** להשתמש ב-`python-bidi`'s `get_display()`.

**עמודת source_url_encoded:** מחושבת אוטומטית ב-`build.py` מ-`source_url`.

עיצוב Excel (ב-`build.py`): כותרת `2F5496` / לבן-מודגש Arial, `wrap_text`, `freeze_panes='A2'`,
תאי עברית `Alignment(horizontal='right', readingOrder=2, wrap_text=True)`, גיליון `rightToLeft=True`.
